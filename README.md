# 筑迹 · 中国古代建筑时空图谱

本轮固定扩充到50座：原15座保留，新增35座；不继续扩至100座。首页以中央图谱、少量统计和按需打开的建筑书组成。

## 使用

双击 `index.html` 可以完整离线打开。也可双击 `启动预览.cmd`，或执行 `node server.mjs` 后访问 <http://127.0.0.1:4748>。无需npm依赖。
直接访问<https://zhuji-worker.zhuji-atlas.workers.dev/>即可在线打开

## 图谱与建筑书

- 年代相近的建筑自动聚合，圆环各色段表示类型数量占比，中心数字表示建筑数。点击圆点展开名录，再选建筑翻书；独立建筑单击即可打开。
- “＋”“−”缩放年代窗口，“全览”恢复全库视野；下方滑块移动窗口。缩放只改变视野，不覆盖类型、搜索、材料等筛选条件。
- 全部可见点位统一显示名称；独立点显示完整建筑名，聚合点统一显示首个建筑名与数量。名称通过移动和细引线避让，不因空间不足或选中状态隐藏；“名称”开关统一显示或隐藏全部标签。单体按所录年代起点定位，聚合点取成员起点均值；范围横线不一定代表连续施工。
- 50本书均包含历史、建筑故事、四行原创题咏、图版、概念模型和来源。题咏明确为现代原创，不冒充古人作品。
- 支持章节书签、前后翻页、左右方向键、Home/End、Escape。关闭书籍保留筛选并回到对应图谱点。
- “图版”章可打开完整尺寸、构件、时间记录与来源档案。
- “分析”窗口保留朝代、类型、材料、结构交叉和年代筛选。时间轴相近点位单独避让。

图谱涵盖七个现代原址地域分组，不画古代疆界。连线只辅助同类型时序阅读，不代表交通路线或技术传承。单体点大小不编码规模。

## 固定50座的资料口径

50个具名样本中，民居16、官府6、皇宫14、桥梁14；资料来源75条，数值记录111项（62项尺寸、49项构件或空间计数）。这是文献精选样本，不是全国古建筑普查，不用样本占比推断全国存量或营造趋势。

八类字段有值率为374/400，即93.5%。扩充前的15条仍保留原有119/120字段、41项尺寸及24项计数。新增记录中没有可按范围引用的尺寸，就保持空数组并列待核实项；有值率不代表证据质量或完整测绘。

材料包含文献直接记载及明确说明依据的结构体系归类。直隶总督署、南阳府衙、淮安府署整体主承重材料未确认；未知不归为0或仅凭屋瓦推断。

尺寸记录各自的 `relation`（exact/approx/gt/gte）、单位、对象范围与source ID。精确值、约数、下限不可混为一谈；局部门洞、单体殿堂、建筑群占地不直接横向比较总面积。

始建、建成、重建、最早现存遗构与时期范围分别注明。例如霍州署大堂按元代断代范围；平遥县衙1346标定最早现存附属遗构；王家大院为清康熙至嘉庆陆续营建。裕昌楼的1308与元末明初记载保留分歧；武英殿明初范围是明确标注的整理区间，不是已证实的施工工期。

来源既包括博物馆、政府、地方志、高校和采访，也有少数明确标为辅助的百科与旅游介绍。辅助资料不升级为原始测绘或工程档案。每条参考可在来源目录和建筑档案中查阅。

## 图片与概念模型

图版共50条：47张建筑照片、2张历史图版、1张原创示意。照片及历史图版共49个本地文件，均保留作者、原文件页、许可链接和显示裁切说明。淮安府署未取得已核对授权的实景照片，使用明确标注的原创院落形制示意。

霍州署采用1558年州署平面图，不冒充元代大堂照片；宝带桥采用民国历史照片；文华殿为穿廊，武英殿为檐部细部。荫余堂迁建外观、泸定桥现代安全网以及中山桥后期加固形制分别说明。

图片分别遵循原作者的CC BY、CC BY-SA、CC0或公版声明，重用时保留各自署名与许可；它们不会自动转为项目自有版权。

模型采用原创建筑概念图，区别圆形土楼、方形土楼、院落群、工字殿、三层楼阁、多孔桥、桥亭、木拱廊桥和铁桁架。几何按实际绘图边界居中，模型框与说明分开排版；屋顶闭合，天井开口属于围合空间设计。图稿使用的坐标为绘图单位，不是新增的建筑测绘尺寸。

## 文件与维护

- `data/architectures.json`：50条规范记录、75条来源、尺寸、构件、年代依据、缺失项及新增书页内容。
- `data/source-register.json`、`data/measurements.csv`、`data/coverage.csv`：来源、111条数值及字段覆盖。
- `data/50座扩充报告.md`：本轮数量、来源性质、图版与待核实项。`data/补数报告.md` 保留首轮15样本的历史补数说明。
- `data/photo-credits.json`、`photo-data.js`、`assets/photos/`：图片授权元数据与离线文件。
- `book-data.js`：原15本书内容；新35本书内容从规范JSON生成到 `expansion-books.js`。
- `atlas-map.js`、`atlas-scale.css`：聚合、缩放、窗口移动与新增结构矩阵布局。
- `architecture-art.js`、`architecture-variants.js`：原始模型与新增形制概念图。
- `app.js`、`book.js`：数据联动与翻书；基础样式沿用原有样式文件。

修改规范JSON后运行 `npm run build:data`，统一验证引用并生成JS、CSV与新增书页副本。不要手填统计总数。

## 验证

`npm test` 检查数据有效性、原15条保留、50条统计守恒、日期筛选、聚合守恒、书页与图片资产。

`node verify.mjs` 用已安装的Windows Edge逐座从主图打开50本书，检查图版、故事、题咏、缩放、筛选、导出和离线浏览，结果保存到 `qa/verification.json`。

`node verify-art.mjs --after` 检查所有屋顶网格边界，以及50座建筑在“故事”“图版”页和1920、1440、1366、390像素屏幕的居中与完整显示，结果保存到 `qa/model-verification.json`。

## 位置与训练说明

本项目保存在“训练/练手项目/筑迹”。已移除无关专题。参考项目仅用于用户认可的交互结构，未复制其名称、素材或数据。

设计参考本地2026通知的1911年前古建筑主题，不收录庙宇、宝塔作为样本。正式参赛需按当届通知核对对象范围、授权、源文件和AI工具使用规定。本项目使用Codex辅助设计与编程，应如实记录技术路径。
